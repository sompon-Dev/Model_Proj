คำอธิบายเส้นข้อมูล

ชื่อเส้นจาก → ไปข้อมูลที่ส่งในโค้ดจริง
newsong_list12 → ผู้ดูแลระบบรายชื่อเพลงที่รอเทรน (newsong_id, ชื่อเพลง, ศิลปิน)GET /Train_Song
update_requestผู้ดูแลระบบ → 12newsong_id ของเพลงที่ติ๊กเลือกPOST /Train_Song/update_model
song_request12 → แฟ้มข้อมูลเพลงสำหรับฝึกnewsong_id ที่ต้องการSELECT … WHERE newsong_id = ANY(...)
newsong_lyricsแฟ้มข้อมูลเพลงสำหรับฝึก → 12ชื่อเพลง, ศิลปิน, เนื้อเพลงผลของ SELECT ข้างบน
current_indexแฟ้มโมเดลค้นหา → 12embedding และ metadata ของเพลงเดิมupdate_index() โหลดไฟล์ index เดิม
new_song_index12 → แฟ้มโมเดลค้นหาchunk + E5 embedding ของเพลงใหม่ ต่อท้าย indexchunks_embeddings.pt, chunks_metadata.pkl แล้ว reload_index()
delete_trained_song12 → แฟ้มข้อมูลเพลงสำหรับฝึกnewsong_id ที่เทรนสำเร็จ (ลบเฉพาะตอนสำเร็จ)DELETE FROM "Train_Song" WHERE newsong_id = ANY(...)
update_result12 → ผู้ดูแลระบบสำเร็จ / ไม่สำเร็จ และจำนวนเพลงที่เทรนGET /Train_Song/update_model/{job_id}
