ระบบเพิ่มเพลงเข้าโมเดล

AddSong.js → Render (main.py) → Supabase  |  UpdateModel.js → Render → Modal (Ver.5/API.py)

ช่วงที่ 1: AddSong

บันทึกเพลงลง database ครบทุกตาราง และพักเนื้อเพลงไว้ใน Train_Song (คิวรอเทรน)

ช่วงที่ 2: UpdateModel

ดึงเพลงจากคิวไปทำ embedding บน Modal แล้วลบเพลงที่เทรนสำเร็จออกจากคิว

ตารางที่เกี่ยวข้อง

  • AddSong: Song, Genre / Genre_Song, Mood / Mood_Song, Train_Song, trending_song ทำเป็น transaction เดียว ถ้าพังกลางทางจะ rollback ทั้งหมด
  • UpdateModel: ใช้แค่ Train_Song (SELECT แล้ว DELETE) ส่วนที่ถูกแก้อีกที่คือไฟล์ index บน Modal (chunks_embeddings.pt, chunks_metadata.pkl)
