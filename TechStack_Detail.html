Tech Stack ของ LyriSeek

เทคโนโลยีทั้งหมดที่ใช้ในโปรเจกต์ แต่ละตัวคืออะไร ทำหน้าที่อะไร และต่อกันอย่างไร สรุปจากโค้ดและเวอร์ชันที่ติดตั้งจริงในเครื่องนี้

⚠️ โหลดตัวสร้างผัง (Mermaid) ไม่ได้ ไฟล์นี้ต้องต่ออินเทอร์เน็ตตอนเปิดครั้งแรก กรุณาตรวจสอบการเชื่อมต่อแล้วรีเฟรชหน้านี้
สรุปสั้นที่สุด: แอปมือถือเขียนด้วย JavaScript (React Native + Expo) คุยกับ server ที่เขียนด้วย Python (FastAPI) ผ่าน HTTP/JSON ฝั่ง server แบ่งเป็นสองงาน: ค้นหาเพลงด้วยโมเดลภาษา (PyTorch + sentence-transformers) และจัดการข้อมูลผู้ใช้/เพลงใน PostgreSQL
3 ภาษาJavaScript (แอป), Python (server + โมเดล), SQL (ฐานข้อมูล)
2 serverAPI.py พอร์ต 8002 (ค้นหา), main.py พอร์ต 8000 (ฐานข้อมูล)
2 ที่เก็บข้อมูลPostgreSQL (ผู้ใช้/เพลง) และไฟล์ index .pt/.pkl (ใช้ค้นหา)
1 โมเดลmultilingual-e5-base สำเร็จรูป ไม่ได้เทรนเอง
ฝั่งแอป (Frontend) ฝั่ง server (Backend) โมเดล / ML ข้อมูล เครื่องมือพัฒนา ข้อสังเกต
1 ภาพรวมเป็นชั้น 2 ค้นหาผ่านอะไรบ้าง 3 สมัครสมาชิกผ่านอะไรบ้าง 4 ตอนรันระบบ 5 เครือข่าย 6 ตารางเทคโนโลยี 7 ข้อสังเกต

เทคโนโลยีเวอร์ชันคืออะไร / ทำอะไรในโปรเจกต์นี้อยู่ที่ไฟล์

7ข้อสังเกตเกี่ยวกับการเลือกใช้ Tech Stack

  1. สองภาษา สองโลก: แอปเป็น JavaScript ส่วน server เป็น Python สองฝั่งไม่ได้แชร์โค้ดกัน คุยกันผ่าน HTTP/JSON เท่านั้น จึงเปลี่ยนฝั่งใดฝั่งหนึ่งได้อิสระ ตราบใดที่รูปแบบข้อมูลตรงกัน
  2. แยก server เป็นสองตัว: งานค้นหา (หนัก ต้องโหลดโมเดล เริ่มช้า) แยกจากงานฐานข้อมูล (เบา เริ่มเร็ว) ข้อดีคือแก้ฝั่งฐานข้อมูลได้โดยไม่ต้องโหลดโมเดลใหม่ ข้อแลกเปลี่ยนคือแอปต้องรู้ที่อยู่ของสอง server
  3. ที่อยู่ผูกกับ IP ในโค้ด: Homeuser.js และ Register.js เขียน 192.168.1.7 ตรงๆ ถ้า IP เครื่องเปลี่ยน ต้องแก้ทุกไฟล์ ทางเลือกคือเก็บที่อยู่ไว้ที่ไฟล์เดียว หรือใช้ 10.0.2.2 บน emulator
  4. ใช้ HTTP ไม่ใช่ HTTPS: เหมาะกับการพัฒนาในเครือข่ายภายใน ถ้าจะเปิดใช้งานจริงควรเพิ่ม HTTPS และระบบยืนยันตัวตน
  5. โมเดลรันบน CPU: PyTorch ที่ติดตั้งเป็นรุ่น CPU สำหรับข้อมูล 79 เพลง เพียงพอ ถ้าเพลงเพิ่มมากหรือเปลี่ยนไปใช้โมเดลใหญ่ขึ้น (เช่นตระกูล Qwen3-Embedding) อาจต้องพิจารณา GPU
  6. เก็บข้อมูลสองที่ยังไม่เชื่อมกัน: เพลงที่ค้นได้อยู่ในไฟล์ index ส่วนตาราง Song ใน PostgreSQL เป็นข้อมูลอีกชุดหนึ่ง ถ้าอยากให้ตรงกัน ต้องออกแบบขั้นตอนสร้าง index จากฐานข้อมูล
