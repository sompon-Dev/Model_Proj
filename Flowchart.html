Flowchart การทำงานของระบบ LyriSeek

ผังการทำงานทั้งหมดตั้งแต่เตรียมข้อมูล เปิดระบบ ค้นหาเพลง ไปจนถึงสมัครสมาชิก สร้างจากโค้ดจริงในโฟลเดอร์ Thesis

⚠️ โหลดตัวสร้างผัง (Mermaid) ไม่ได้ ไฟล์นี้ต้องต่ออินเทอร์เน็ตตอนเปิดครั้งแรก กรุณาตรวจสอบการเชื่อมต่อแล้วรีเฟรชหน้านี้

วิธีอ่านผัง อ่านจากบนลงล่าง (หรือซ้ายไปขวา) ตามลูกศร

  • วงรี / ทรงแคปซูล = จุดเริ่มหรือจุดจบ
  • กล่องสี่เหลี่ยม = ขั้นตอนที่โปรแกรมทำ
  • ข้าวหลามตัด (◇) = จุดตัดสินใจ มีลูกศรแยกออกไปตามคำตอบ
  • เส้นประ = สิ่งที่เกิดขึ้นควบคู่กัน หรือยังไม่ได้เชื่อมต่อจริง
  • กด + / − เหนือแต่ละผังเพื่อขยายหรือย่อ ผังใหญ่เลื่อนดูได้
ฝั่งแอปมือถือ ฝั่ง Server / โปรแกรม Python ฐานข้อมูล / ไฟล์ข้อมูล ยังไม่ได้ทำ / ข้อสังเกต Error

8สถานะปัจจุบัน: อะไรทำงานจริง อะไรยังไม่เสร็จ

สรุปจากโค้ดที่มีอยู่ ณ ตอนที่เขียนไฟล์นี้

ส่วนสถานะรายละเอียด
ค้นหาเพลงด้วยเนื้อร้องทำงานจริงHomeuser → API.py → Search.py → แสดงผล 5 อันดับ
กรอง genre / mood ตอนค้นหายังไม่ทำงานแอปส่ง genres และ moods ไปด้วย แต่ API.py ไม่ได้ใช้ (QueryRequest มีช่อง text ช่องเดียว)
สมัครสมาชิกทำงานจริงบันทึกลงตาราง User พร้อมเข้ารหัสรหัสผ่านด้วย bcrypt
ยืนยัน OTPยังไม่ทำกด Verify แล้วไปหน้า Login ทันที ไม่ได้ส่งหรือตรวจรหัส
Loginยังไม่ทำกด Login! แล้วไปหน้า Homeuser ทันที ไม่ได้ตรวจ username / password
Addsong (เพิ่มเพลง)ยังไม่ทำฟังก์ชัน handleEnter แค่ console.log ยังไม่ส่งไป main.py
AdminPageบางส่วนปุ่ม Add Song ไปหน้า Addsong ได้ ปุ่มอื่นไปหน้าที่ยังไม่ได้ลงทะเบียน และยังไม่มีปุ่มใดพามาหน้านี้
Resultหน้าตาเท่านั้นเป็นการ์ดจำลอง ผลการค้นหาจริงแสดงในหน้า Homeuser ไม่ได้ใช้หน้านี้
endpoint ของ main.pyมีบั๊กตาราง Train_Song และ Song มี endpoint อ่าน/แก้ไขที่ใช้ชื่อตารางและคอลัมน์ผิด และกลุ่ม /…/all น่าจะถูกจับคู่กับ /{id} ก่อน ดูส่วนที่ 3 ของ Document.md
ค้นหาเพลงกับฐานข้อมูลยังแยกกันเพลงที่ค้นได้มาจากไฟล์ index ที่สร้างจาก Dataset ไม่ได้มาจากตาราง Song ใน PostgreSQL
